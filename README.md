## 📖 About

**Melody Hub** is a Spotify-inspired music player built using **HTML, CSS, and JavaScript**. The application provides a smooth and responsive user experience with modern UI elements, allowing users to browse and play songs directly from the browser.

It focuses on creating a visually appealing interface while demonstrating frontend development skills such as DOM manipulation, responsive layouts, animations, and interactive controls.

---

## ✨ Features

🎵 Beautiful Spotify-inspired interface

🔍 Search songs instantly

▶️ Play, Pause, Next & Previous controls

📂 Browse songs by albums

📱 Fully Responsive Design

🎚️ Interactive Progress Bar

🔊 Volume Control
